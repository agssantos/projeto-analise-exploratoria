# Análise Exploratória de Dados em um Dataset de Pokémon

## Visão Geral do Projeto
Este projeto envolve a realização de uma análise exploratória de dados (EDA) em um dataset de Pokémon para descobrir insights e tendências utilizando Python. Várias bibliotecas como Pandas, Matplotlib e Pyplot foram usadas para analisar, visualizar e processar os dados.

## Funcionalidades
- **Análise do Dataset**: Exploração detalhada do dataset de Pokémon, incluindo estatísticas e análise estrutural.
- **Limpeza de Dados**: Tratamento de valores ausentes, renomeação de colunas e transformação de variáveis categóricas.
- **Visualizações**: Criação de visualizações informativas para identificar tendências e padrões nos dados.

## Tecnologias Utilizadas
- **Python**: Linguagem de programação principal.
- **Pandas**: Para manipulação e análise de dados.
- **Matplotlib & Pyplot**: Para visualização de dados.

## Dataset
O dataset inclui vários atributos de Pokémon, como:
- Nome
- Tipo(s)
- Atributos base (Ataque, Defesa, Velocidade, etc.)
- Geração
- Status de lendário

O dataset está disponível publicamente e pode ser acessado em [Kaggle](https://www.kaggle.com/) ou outros repositórios de código aberto.

## Principais Etapas da Análise
1. **Carregamento de Dados**: O dataset foi carregado utilizando Pandas e sua estrutura foi examinada.
2. **Limpeza de Dados**:
   - Tratamento de valores ausentes ou inconsistentes.
   - Conversão de dados categóricos para formatos numéricos para análise.
3. **Análise Exploratória de Dados**:
   - Realização de estatísticas descritivas nos atributos numéricos.
   - Visualização das relações entre as principais características.
   - Análise de distribuições e correlações.
4. **Visualização**:
   - Criação de gráficos de barras, histogramas, gráficos de dispersão e heatmaps.
   - Apresentação de tendências como médias de atributos por geração de Pokémon.
